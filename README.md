# Vision Zero BCN

Data-driven road safety for motorcyclists in Barcelona. We analyse every motorcycle crash in the Guàrdia Urbana open data (2015–2025), propose a concrete measure for each risk point, route it to the department that can act on it, and learn from what happens after each measure is applied.

- `index.html` — project overview
- `demo/` — digital twin demo (public view; the technical room is encrypted and opens with an evaluator password)

Data: Guàrdia Urbana de Barcelona (Open Data BCN), Meteocat XEMA, Barcelona City Council neighbourhood boundaries.
